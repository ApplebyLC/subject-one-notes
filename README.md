## 内容组织

本笔记按科目一考试大纲编排，分为法规基础、交通信号、安全行车和操作基础四部分，共九篇，另附 57 道自测题。

| 部分 | 篇数 | 主要内容 |
|------|------|----------|
| 一、法规基础（01–04） | 4 | 驾驶证、车辆登记、记分、处罚 |
| 二、交通信号（05–06） | 2 | 信号灯、标志、标线、交警手势 |
| 三、安全行车（07） | 1 | 通行原则、限速、特殊路段、高速 |
| 四、操作基础（08–09） | 2 | 操纵机构、安全装置、检查、油液 |

每篇结构一致，依次为：一句话考点、分层要点、速记口诀、易混对比、数字汇总。

## 本地运行

```bash
# 1. 安装依赖
pip install mkdocs-material

# 2. 本地预览
mkdocs serve
# 打开 http://127.0.0.1:8000

# 3. 构建静态网页
mkdocs build
# 生成的静态文件在 site/ 目录
```

# 操纵机构·开关与安全装置

> **一句话考点**：驾驶靠 **转向盘 + 三踏板 + 变速杆 + 手刹**；安全装置分**主动**（预防）与**被动**（保护）；车辆性能看**制动性、操纵稳定性、通过性**。

---

## 一、驾驶操纵机构

### 1.1 转向盘（方向盘）

- **作用**：通过转向机构控制转向轮左右转动，改变行驶方向
- **握法**：双手分别握 **3 点与 9 点**方向，四指由外向内握，拇指自然伸直，手肘微弯，**轻握不要过紧**
- **平直路**：左手为主、右手为辅，小角度修正，**轻而慢**，避免过急过大
- **转弯**：双手操作，一手推送、一手辅助拉接；**车速越高，转动幅度越小**
- 转向盘有自动回正功能，但不能让其自行回转，双手需保持可控状态

### 1.2 三个踏板

| 踏板 | 作用 | 操作要点 |
|------|------|---------|
| **离合器踏板** | 控制发动机与变速器动力的结合与分离（手动挡） | 左脚前脚掌，膝/踝关节伸曲；踩下分离、抬起结合；**不用脚尖或脚心**；行驶中脚不要放在离合上，**避免长时间半联动** |
| **制动踏板** | 行车制动，用于减速和停车 | 右脚前脚掌，膝关节伸曲；踩下制动、松抬解除；提前轻踩减速，**尽量避免紧急制动** |
| **加速踏板（油门）** | 控制进气量/喷油量，改变发动机转速和动力 | 右脚跟为支点，脚掌轻踏；踩下转速提高、动力增加；起步轻踩，注意油门/离合/手刹配合 |

**关键习惯**：不踩加速踏板时，右脚掌应放在制动踏板上，防止错把油门当刹车。

### 1.3 变速器操纵杆

| 类型 | 档位 | 要点 |
|------|------|------|
| **手动档** | N 空档、R 倒车档、1–5（或 6）前进档 | 掌心抵住球头，五指自然握；腕/肘发力；换档时**两眼注视前方，不低头**；动作自然流畅；**加减档逐级进行，不得越级**；挂倒档须车辆停稳 |
| **自动档** | P 驻车档、R 倒车档、N 空档、D 前进档、S（原文 R）二档、L 低速档 | 手掌轻握球头，按下锁止按钮换档；P 驻车/启动发动机，D 正常行驶，L/S 上下长陡坡 |

### 1.4 驻车制动器（手刹）

- **作用**：车辆停稳后固定车辆，防止坡道溜车
- **形式**：驻车操纵杆、驻车制动踏板、电子驻车开关（一辆车只装一种）
- **操作杆**：拇指放按钮上，四指握手柄；制动时**不按按钮直接上拉**，听到"咔咔"3–5 响；解除时上拉同时按按钮放到底
- **踏板式**：踏下制动，再次踏下自动解除
- **电子式**：停车后按下制动，挂入行驶档位加油门即自动解除

## 二、各类开关

| 开关 | 作用与要点 |
|------|-----------|
| **点火开关** | 4 个位置：**0/LOCK**（关闭、拔钥匙、转向锁止）、**1/ACC**（发动机关闭，其他电气可用）、**2/ON**（发动机工作）、**3/START**（启动机启动）。一键启动需智能钥匙在场；**每次启动不超过 5 秒，连续三次不成功应检查故障** |
| **刮水器/洗涤器** | 向上拨单次；向下三档：间歇（小雨雪）、慢速（中雨雪）、快速（大雨雪/暴雨）；向内拉喷洗涤液 |
| **雾灯开关** | 前/后雾灯分别控制；部分车需示廓灯、近光灯亮时雾灯才工作 |
| **灯光信号组合开关** | 控制前照灯（远/近光）、转向灯（上提右转、下拉左转）、示廓灯、信号灯光 |
| **除雾器开关** | 减少前后风窗及外后视镜的湿气、雾气和霜；**工作约 15 分钟自动关闭**；再次按下手动关闭 |

> 🧪 自测：[各类开关](99_科目一自测题.md#08)

## 三、主动安全装置

> **定义**：使驾驶人自由平稳控制车辆，主动消除或提醒消除安全隐患。

### 3.1 仪表

| 仪表 | 单位/含义 |
|------|----------|
| 速度表 | km/h，指示当前车速 |
| 里程表 | km，累计总里程；日里程表可归零 |
| 发动机转速表 | 1000 转/分；运转时指针**不得超过红色警示区** |
| 水温表 | ℃；**C 低、H 高**；指针进入红区说明温度过高 |
| 燃油表 | **0 空、1 满**；指针到红色警告线内需及时加油 |

### 3.2 指示灯与报警灯

| 灯          | 颜色  | 含义                      |
| ---------- | --- | ----------------------- |
| 发动机故障灯     | —   | 启动自检亮、启动后灭；常亮表示发动机系统故障  |
| 机油压力过低灯    | 红色  | 机油压力低于标准，继续行驶会异常磨损      |
| 水温警示灯      | 红色  | 发动机温度过高，易爆缸             |
| 充电指示灯（电瓶灯） | 红色  | 发电系统工作状态                |
| 刹车系统故障灯    | 红色  | 制动系统异常（制动液、刹车片、手刹）      |
| ABS 故障灯    | 黄色  | ABS 系统故障；启动后几秒应熄灭，常亮即故障 |
| 安全带指示灯     | 红色  | 座椅有人未系安全带，伴报警音          |
| 安全气囊故障灯    | 红色  | 气囊系统故障，碰撞时可能不弹出         |
| 转向助力报警灯    | —   | 电子助力转向系统故障              |
| 胎压报警灯      | 黄色  | 胎压不足或四轮胎压差异过大           |

### 3.3 照明与信号装置

| 灯 | 作用 |
|----|------|
| 前照灯（大灯） | 夜间/光线不好时照明，含远光、近光 |
| 示廓灯（小灯） | 夜间/特殊天气标示车宽 |
| 雾灯 | 雾、雨、雪、风尘天气照明兼信号 |
| 转向信号灯 | 起步、转弯、变道、停车时交替闪光 |
| 制动灯 | 制动、减速、停车时向后方发出信号 |
| 倒车灯 | 挂倒档自动开启，警示后方，夜间兼照明 |
| 尾灯 | 夜间向后方标示车辆位置 |
| 牌照灯 | 照明号牌，便于夜间识别 |
| 危险报警闪光灯（双闪） | 故障停车或紧急情况时使用，警告后方 |

### 3.4 儿童安全座椅

- 应置于**后排座位**，有束缚设备，碰撞或急减速时减缓冲击、限制身体移动
- 安装方式：**车带安全带固定、ISOFIX 装置固定、LATCH 固定**
- 按使用手册固定和使用

### 3.5 其他安全设备

| 设备 | 作用 |
|------|------|
| 喇叭 | 发出音响信号，警告行人、提醒车辆 |
| 后视镜 | 反映后方、侧方、下方情况，扩大视野，判断后车距离 |
| 三角警告牌 | 塑料反光材料，故障/事故时提醒后方避让，防二次事故 |
| 灭火器 | 多为手提式，扑救车辆初起火灾 |

### 3.6 防抱死制动系统（ABS）

- **作用**：紧急制动时防止车轮抱死，保持前轮转向能力，消除跑偏、侧滑，缩短制动距离
- **使用要点**：
  - 紧急制动可**用力踏**制动踏板
  - 不要依赖 ABS 缩短制动距离（冰雪路面尤其无效）
  - ABS 起作用时踏板会**震动，不可松抬**，持续用力踩

## 四、被动安全装置

> **定义**：车辆发生事故时提供对驾乘人员的保护。

| 装置 | 作用与要点 |
|------|-----------|
| **安全头枕** | 被追尾时保护颈椎；调整高度使**头枕中心与后脑中心平齐**；过高不能缓冲、过低易致颈椎折断，调节不当会很危险 |
| **安全带（生命带）** | 碰撞或紧急制动时固定驾乘人员，减少伤害 |
| **安全气囊** | 碰撞时迅速膨胀形成气垫；**必须与安全带配套使用**，不系安全带时气囊引爆可能造成严重伤害甚至致命（尤其儿童） |
| **逃生出口** | 车窗、天窗、后备箱；车门车窗打不开时，用安全锤等敲击车窗四角或打开天窗/后备箱逃生 |

**安全带使用要点**：
- 松紧以**两个手指**为宜
- 高度不过高不过低，紧贴肩膀中间
- 束带不接触颈部、不系在腋下，保持平整
- 孕妇系到**胯骨**上，不勒肚子
- 无人员座位也要保证安全带张紧或系好（防止飞动搭扣伤人）
- 儿童必须使用儿童约束装置

## 五、汽车使用性能

> 汽车使用性能包括动力性、燃油经济性、制动性、操纵稳定性、平顺性、通过性。**与行车安全最密切相关：制动性、操纵稳定性、通过性。**

### 5.1 制动性

| 评价维度 | 含义 |
|---------|------|
| **制动效能** | 迅速降低车速直至停车的能力；与制动力、路面附着力有关；轮胎/制动片磨损过度、湿滑冰雪路面时明显变差 |
| **制动恒定性** | 抵抗**热衰退**和**水衰退**的能力 |
| **制动方向稳定性** | 制动时维持直线或按预定弯道行驶的能力 |

**热衰退**：高速制动或连续下长坡反复制动，制动器温度迅速升高，制动性能急剧下降或失效。
**水衰退**：车轮涉水后制动片与制动鼓/盘间进水，制动性能下降；涉水后应擦干、低速行驶、**间断轻踩制动踏板**恢复。

**方向稳定性差的表现**：
- **制动跑偏**：方向盘固定不动时车辆自动向左/右偏；主因是**左右车轮制动力分配不均匀**
- **制动侧滑**：某一轴或两轴横向滑移；主因是路面湿滑、车轮抱死、猛打方向；**高速制动后轴侧滑易甩尾、掉头**

### 5.2 发动机辅助制动

挂前进挡行驶时完全抬起加速踏板，发动机无燃料供应、转速下降，牵制车辆降速，作用类似制动。**下长坡时应正确使用**。

### 5.3 操纵稳定性

车辆抵抗改变其位置或行驶方向的外界影响的能力，是**高速车辆的生命线**。不良操纵稳定性易引起侧滑或翻车。受车辆结构参数、路面特性、环境（横风）、驾驶人技能影响。

### 5.4 通过性

车辆以足够高平均速度通过各种坏路、无路地带和障碍的能力。

| 指标 | 含义与影响 |
|------|-----------|
| **最小离地间隙** | 满载时除车轮外最低点到地面距离；越大通过障碍能力越强但重心高、稳定性降低；越小通过能力弱但重心低稳定性好 |
| **接近角 / 离去角** | 前后突出点向车轮引切线与路面夹角；越大通过性越好 |
| **纵向通过角** | 空载静止时通过前后轮外缘切线交于车体下部较低部位形成的最小锐角；表征无碰撞通过小丘、拱桥的能力 |
| **纵向通过半径** | 越小通过性越好（原文表述） |
| **最小转弯半径** | 转向盘转到极限时外侧前轮轨迹圆半径；越小越灵活，通过狭窄弯曲地带能力越强 |
| **内轮差** | 前内轮与后内轮转弯半径之差；转弯时前后轮轨迹不重合，只注意前轮可能造成后内轮驶出路面或碰撞 |

> 🧪 自测：[汽车使用性能](99_科目一自测题.md#08)

## 六、速记口诀

| 主题 | 口诀 |
|------|------|
| 转向盘握法 | **三点九点轻握，左手为主右手辅** |

## 七、易混对比

| 易混点 | 区分 |
|--------|------|
| 主动 vs 被动安全装置 | 主动 = 预防/提醒（ABS、仪表、灯光、儿童座椅）；被动 = 事故时保护（头枕、安全带、气囊） |
| 制动跑偏 vs 制动侧滑 | 跑偏 = 车辆自动左/右偏，主因左右制动力不均；侧滑 = 横向滑移，主因路滑/抱死/猛打方向 |
| 热衰退 vs 水衰退 | 热衰退 = 连续制动温度过高；水衰退 = 涉水后进水 |
| 离合器踩下 vs 抬起 | 踩下 = 分离、动力切断；抬起 = 结合、动力传递 |
| 最小离地间隙大 vs 小 | 大 = 通过性强、重心高稳定性差；小 = 通过性弱、重心低稳定性好 |
| 接近角/离去角 vs 纵向通过角 | 前者表征接近/离开障碍物能力；后者表征通过小丘、拱桥能力 |

# 道路通行·装载·高速规定

> **一句话考点**：通行四原则（分道、右侧、按信号、专用车道）；行驶状态看"让行顺序"；高速记住 **120/60、100 米、150 米、200/100/50**。

---

## 一、道路通行基本原则

| 原则 | 内容 |
|------|------|
| **分道行驶** | 划分机动车道/非机动车道/人行道的，各行其道；未划分的，机动车走中间，非机动车和行人走两侧 |
| **右侧通行** | 机动车、非机动车实行右侧通行 |
| **按交通信号通行** | 按信号通行；有交警指挥时按交警指挥；无信号时确保安全畅通 |
| **专用车道** | 专用车道只准许规定车辆通行，其他车辆不得进入 |

### 行驶要求
- 同方向两条以上机动车道：**左侧快速车道、右侧慢速车道**
- 未达到快速车道规定速度的，应在慢速车道行驶
- **摩托车应在最右侧车道行驶**
- 变更车道不得影响相关车道内车辆正常行驶
- 慢速车道内超车时可借用快速车道

### 限速规定

**普通道路**：

| 道路类型 | 限速 |
|---------|------|
| 城市道路（无中心线） | 30 km/h |
| 公路（无中心线） | 40 km/h |
| 同方向只有一条机动车道的城市道路 | 50 km/h |
| 同方向只有一条机动车道的公路 | 70 km/h |

**最高 30 km/h 的特殊情形**：
1. 进出非机动车道，通过铁路道口、急弯路、窄路、窄桥
2. 掉头、转弯、下陡坡
3. 遇雾、雨、雪、沙尘、冰雹，能见度在 **50 米以内**
4. 在冰雪、泥泞道路上行驶
5. 牵引发生故障的机动车

**高速公路**：

| 项目 | 限速 |
|------|------|
| 最高车速 | **120 km/h** |
| 最低车速 | **60 km/h** |
| 小型载客汽车 | 最高 120 km/h |
| 其他机动车 | 最高 100 km/h |
| 摩托车 | 最高 80 km/h |
| 同方向 2 条车道，左侧车道最低 | 100 km/h |
| 同方向 3 条以上车道，最左侧最低 | 110 km/h |
| 同方向 3 条以上车道，中间车道最低 | 90 km/h |

> 限速标志与车道规定不一致时，**按限速标志**。

## 二、行驶状态规定

### 2.1 跟车
- 保持足以采取紧急制动措施的安全距离
- 注视点不要固定在前车，要观察前方 2–3 辆车的动态

### 2.2 变更车道
- 不得影响其他车辆正常行驶
- 有交警发出变更车道手势时，按手势方向变道，腾空指定车道并减速

### 2.3 超车
- 提前开**左转向灯**，变换远近光灯或鸣喇叭
- 前车应降低速度、靠右让路
- 后车确认安全距离后，从**前车左侧**超越；拉开安全距离后开**右转向灯**驶回原车道
- 慢速车道超车可借用快速车道

**不得超车的情形**：
1. 前车正在左转弯、掉头、超车
2. 与对面来车有会车可能
3. 前车为执行紧急任务的警车、消防车、救护车、工程救险车
4. 行经铁路道口、交叉路口、窄桥、弯道、陡坡、隧道、人行横道、市区交通流量大的路段等没有超车条件

### 2.4 会车
1. 减速靠右行驶，与车辆、行人保持安全距离
2. 有障碍路段：**无障碍一方先行**；但有障碍方已驶入而无障碍方未驶入时，**有障碍方先行**
3. 狭窄坡路：**上坡方先行**；但下坡方已行至中途而上坡方未上坡时，**下坡方先行**
4. 狭窄山路：**不靠山体的一方先行**
5. 夜间会车：距对向来车 **150 米以外**改用近光灯；窄路、窄桥与非机动车会车时用近光灯

### 2.5 掉头
- **禁止掉头**：有禁止掉头/禁止左转弯标志标线处；铁路道口、人行横道、桥梁、急弯、陡坡、隧道或容易发生危险的路段
- 允许掉头处不得妨碍正常行驶的车辆和行人
- 提前开左转向灯，按标志指示完成

### 2.6 倒车
- 查明车后情况，确认安全后倒车
- **禁止倒车**：铁路道口、交叉路口、单行路、桥梁、急弯、陡坡、隧道

### 2.7 停车

**停车要求**：在规定地点停放；路边停车选择停车泊位；**禁止在人行道停放**。

**临时停车禁停区域**：

| 区域 | 距离 |
|------|------|
| 交叉路口、铁路道口、急弯路、宽度不足 4 米的窄路、桥梁、陡坡、隧道 | 及**上述地点 50 米以内** |
| 公共汽车站、急救站、加油站、消防栓/消防队门前 | 及**上述地点 30 米以内**（使用该设施的除外） |

**临时停车要求**：
- 不得妨碍其他车辆和行人通行
- 紧靠道路右侧，按顺行方向停放
- 车辆停稳前不得开车门和上下人员
- 驾驶人不得离车；上下人员或装卸物品后立即驶离

**故障停车**：
- 立即开危险报警闪光灯，移至不妨碍交通处
- 难以移动的，持续开启危险报警闪光灯
- 夜间还需开示廓灯和后位灯

## 三、特殊路段通行

### 3.1 交叉路口

**有信号控制**：
- 按导向车道行驶；让已在路口内的车先行
- 左转靠路口中心点左侧，开转向灯，夜间开近光灯
- 放行信号依次通过；停止信号停在停止线外（无停止线停在路口外）
- 右转遇同车道前车等候放行时，依次停车等候
- 无方向指示信号灯时，转弯车让直行车、行人先行
- 相对方向右转车让左转车先行

**无信号控制**：
- 减速慢行，让行人和优先通行车辆先行
- 有标志标线的，让优先通行方先行
- 无标志标线的，进入路口前**停车瞭望，让右方道路来车先行**
- 转弯让直行；相对方向右转让左转
- 准备进入环形路口的，让已在路口内的车先行
- 车道减少或路口排队时，**依次交替通行**

### 3.2 铁路道口及渡口
- 有信号或管理人员：按信号/指挥通行
- 无信号或管理人员：减速或停车，确认安全后通过，**车速不超过 30 km/h**
- 渡口：按渡口人员指挥，指定地点依次待渡，减速慢行

### 3.3 缓行拥堵路段
- 不得借道超车、占用对面车道、穿插等候车辆
- 路口交通阻塞时，依次停在路口外等候，不得进入路口
- 不得从前方车辆两侧穿插或超越
- 不得在人行横道、网状线区域内停车等候
- 车道减少时，每车道一辆依次交替驶入

### 3.4 漫水桥 / 漫水路
- **停车查明水情**，确认积水深度，确认安全后低速通过

## 四、装载与牵引

### 4.1 载物高度限制

| 车辆类型 | 高度限制 |
|---------|---------|
| 重型/中型载货汽车、半挂车 | 从地面起 ≤ **4 米** |
| 载运集装箱的车辆 | ≤ **4.2 米** |
| 其他载货机动车 | ≤ **2.5 米** |
| 摩托车 | ≤ **1.5 米**；长度不超出车身 **0.2 米** |
| 两轮摩托车载物宽度 | 左右各不超出车把 **0.15 米** |
| 三轮摩托车载物宽度 | 不超过车身 |
| 载客汽车行李架载货 | 从车顶起 ≤ **0.5 米**，从地面起 ≤ **4 米** |

- 载物不得超过行驶证核定载质量，长度、宽度不得超出车厢
- 超限不可解体物品：按指定时间、路线、速度行驶，悬挂明显标志
- 危险物品：经公安机关批准，按指定时间/路线/速度，悬挂警示标志并采取安全措施

### 4.2 载人规定
- 公路载客汽车不得超过核定人数；免票儿童不得超过核定人数 **10%**
- 载货汽车车厢**不得载客**；城市道路货运机动车车厢内可临时载作业人员 **1–5 人**（留安全位置）；载物高度超过车厢栏板时货物上不得载人
- 摩托车后座不得乘坐**未满 12 周岁**未成年人；轻便摩托车不得载人

### 4.3 牵引挂车

| 牵引车 | 规定 |
|--------|------|
| 载货汽车、半挂牵引车、拖拉机 | 只允许牵引**一辆**挂车 |
| 小型载客汽车 | 只允许牵引旅居挂车或总质量 **700kg 以下**挂车；挂车不得载人 |
| 载货汽车牵引挂车 | 挂车载质量不得超过本身载质量 |
| 大型/中型载客汽车、低速载货汽车、三轮汽车等 | **不得牵引挂车** |

### 4.4 牵引故障车
1. 被牵引车除驾驶人外不得载人，不得拖带挂车
2. 被牵引车宽度不得大于牵引车
3. 软连接牵引：两车距离 **4–10 米**
4. 制动失效的被牵引车：使用**硬连接**牵引装置
5. 牵引车和被牵引车均开启危险报警闪光灯
- 汽车吊车、轮式专用机械车不得牵引车辆
- 摩托车不得牵引车辆或被其他车辆牵引
- 转向/照明/信号装置失效的故障车：使用专用清障车拖曳

### 4.5 故障处置
- 开危险报警闪光灯，移至不妨碍交通处
- 普通道路：来车方向 **50–100 米**设置警告标志
- 高速公路：来车方向 **150 米以外**设置警告标志，人员转移至护栏外安全区域
- 夜间同时开启示廓灯和后位灯

## 五、灯光与文明礼让

### 5.1 灯光使用

| 情形 | 灯光 |
|------|------|
| 左转、向左变道、准备超车、驶离停车地点、掉头 | 提前开**左转向灯** |
| 右转、向右变道、超车完毕驶回原车道、靠边停车 | 提前开**右转向灯** |
| 雾天 | 雾灯 + 危险报警闪光灯 + 前照灯 + 示廓灯 + 后位灯；同方向近距离跟车不得用远光灯 |
| 夜间无路灯/照明不良/低能见度 | 前照灯 + 示廓灯 + 后位灯；同方向近距离跟车不得用远光灯 |
| 夜间通过急弯、坡路、拱桥、人行横道、无信号路口 | **交替使用远近光灯**示意 |
| 夜间会车 | 距对向来车 **150 米以外**改近光灯；窄路窄桥与非机动车会车用近光灯 |
| 故障/事故停车 | 危险报警闪光灯 + 警告标志（夜间加示廓灯、后位灯） |
| 急弯、坡道顶端等影响安全视距路段，或超车、紧急情况 | 减速慢行，**鸣喇叭**示意 |

### 5.2 文明礼让
- **行人/非机动车**：无信号路口减速让行；转弯让直行行人；人行横道减速，行人通过时停车让行；无信号道路遇行人横过及时避让
- **警车、消防车、救护车、工程救险车**执行紧急任务时：及时让行
- **道路养护车、工程作业车、洒水车、清扫车**作业时：注意避让
- **校车**：
  - 同方向一条车道：校车停靠时，后方车辆**停车等待，不得超越**
  - 同方向两条以上车道：校车停靠车道后方和相邻车道车辆停车等待，其他车道减速通过
  - 后方等待车辆**不得鸣喇叭或用灯光催促**

### 5.3 禁止行为
1. 车门、车厢未关好时行车
2. 前后窗范围内悬挂、放置妨碍视线物品
3. 拨打接听手持电话、观看电视等妨碍安全驾驶
4. 下陡坡时熄火或空挡滑行
5. 向道路上抛撒物品
6. 驾驶摩托车手离车把或在车把上悬挂物品
7. 连续驾驶超过 **4 小时**未停车休息，或休息少于 **20 分钟**
8. 在禁止鸣喇叭区域/路段鸣喇叭
9. 驾驶安全设施不全或机件不符合技术标准的机动车
10. 服用国家管制精神药品/麻醉药品、患有妨碍安全驾驶疾病、过度疲劳时驾驶

## 六、高速公路通行规定

### 6.1 禁入车辆
行人、非机动车、拖拉机、轮式专用机械车、铰接式客车、全挂拖斗车，以及其他设计最高时速**低于 70 公里**的机动车，不得进入高速公路。

### 6.2 进出高速
- 驶入：开**左转向灯**，不妨碍已在高速内车辆正常行驶的情况下驶入
- 驶离：开**右转向灯**，驶入减速车道，降低车速后驶离

### 6.3 跟车距离

| 车速         | 最小车距                 |
| ---------- | -------------------- |
| > 100 km/h | **100 米以上**          |
| ≤ 100 km/h | 可适当缩短，但**不得少于 50 米** |

### 6.4 低能见度

| 能见度     | 灯光              | 车速            | 车距          |
| ------- | --------------- | ------------- | ----------- |
| < 200 米 | 雾灯、近光灯、示廓灯、前后位灯 | ≤ **60 km/h** | > **100 米** |
| < 100 米 | 上述 + 危险报警闪光灯    | ≤ **40 km/h** | > **50 米**  |
| < 50 米  | 上述 + 危险报警闪光灯    | ≤ **20 km/h** | 从最近出口尽快驶离   |

### 6.5 应急车道
- 专供工程救险、消防救援、医疗救护、民警执行紧急公务等车辆使用
- 非紧急情况不得行驶或停车
- 违规使用：**罚款 200 元 + 记 6 分**

### 6.6 高速故障处理
- 立即开危险报警闪光灯，移至不妨碍交通处
- 难以移动的：持续开启危险报警闪光灯，在来车方向 **150 米以外**设置警告标志
- 人员迅速转移到右侧路肩或应急车道内，并迅速报警
- 无法正常行驶的，由救援车、清障车拖曳、牵引

### 6.7 高速禁止行为
- 倒车、逆行、穿越中央分隔带掉头、在车道内停车
- 在匝道、加速车道或减速车道上超车
- 骑、轧车行道分界线或在路肩上行驶
- 非紧急情况在应急车道行驶或停车
- 试车或学习驾驶机动车
- 载货汽车车厢载人
- 两轮摩托车载人

## 八、易混对比

| 易混点      | 区分                                                            |
| -------- | ------------------------------------------------------------- |
| 临时停车禁停距离 | 交叉路口/铁路道口/急弯/窄路/桥梁/陡坡/隧道：**50 米内**；公交站/急救站/加油站/消防栓：**30 米内**  |
| 故障警告标志距离 | 普通道路 **50–100 米**；高速公路 **150 米以外**                            |
| 会车先行规则   | 有障碍：无障碍方先行（但障碍方已驶入则障碍方先行）；坡路：上坡方先行（但下坡方已到中途则下坡方先行）；山路：不靠山体方先行 |
| 高速跟车     | >100km/h → **100 米**；≤100km/h → 最少 **50 米**                   |
| 校车让行     | 一条车道：后方**停车等待**；两条以上：停靠车道及相邻车道**停车**，其他车道减速                   |
| 牵引故障车    | 软连接 **4–10 米**；制动失效用**硬连接**                                   |

## 九、数字汇总

| 项目 | 数值 |
|------|------|
| 普通道路特殊情形限速 | 30 km/h |

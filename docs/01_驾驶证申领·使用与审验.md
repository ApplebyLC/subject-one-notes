# 驾驶证申领·使用与审验

> **一句话考点**：驾驶证共 **17 类**；有效期 **6/10/长期**；科目一、三 **90 分**合格、科目二 **80 分**；实习期 **12 个月**；学习驾驶证明有效期 **3 年**。

---

## 一、驾驶证许可制度与 17 类准驾车型

### 1.1 许可制度

- 驾驶机动车的人员，应依法取得驾驶证并**随身携带**
- 按驾驶证载明的**准驾车型**驾驶，随身携带驾驶证和行驶证

### 1.2 17 类驾驶证

| 代号     | 类别      | 代号     | 类别             |
| ------ | ------- | ------ | -------------- |
| **A1** | 大型客车    | **C1** | 小型汽车           |
| **A2** | 重型牵引挂车  | **C2** | 小型自动挡汽车        |
| **A3** | 城市公交车   | **C3** | 低速载货汽车         |
| **B1** | 中型客车    | **C4** | 三轮汽车           |
| **B2** | 大型货车    | **C5** | 残疾人专用小型自动挡载客汽车 |
|        |         | **C6** | 轻型牵引车          |
| **E**  | 普通二轮摩托车 | **D**  | 普通三轮摩托车        |
| **M**  | 轮式专用机械车 | **F**  | 轻便摩托车          |
| **P**  | 有轨电车    | **N**  | 无轨电车           |

### 1.3 准驾车型要点 

| 驾照     | 可驾驶                                                      |
| ------ | -------------------------------------------------------- |
| **A1** | 大型客车 + 城市公交、中型客车、大型货车、小型汽车、小型自动挡、低速载货、三轮汽车、轮式专用机械        |
| **A2** | 重型/中型全挂/半挂牵引车 + 中型客车、大型货车、小型汽车、小型自动挡、低速载货、三轮汽车、轮式专用机械    |
| **A3** | 核载 **10 人以上**城市公共汽车 + 小型汽车、小型自动挡、低速载货、三轮汽车               |
| **B1** | 中型载客汽车（含核载 **10–19 人**城市公交）+ 小型汽车、小型自动挡、低速载货、三轮汽车、轮式专用机械 |
| **B2** | 重型/中型载货汽车、专项作业车 + 小型汽车、小型自动挡、低速载货、三轮汽车、轮式专用机械            |
| **C1** | 小型/微型载客 + 轻型/微型载货及专项作业车 + 小型自动挡、低速载货、三轮汽车                |
| **C2** | 小型/微型自动挡载客 + 轻型/微型自动挡载货；**C2 以上可驾驶 C5**                  |
| **C3** | 低速载货汽车                                                   |
| **C4** | 三轮汽车                                                     |
| **C5** | 残疾人专用小型/微型自动挡载客汽车                                        |
| **C6** | 轻型牵引挂车（总质量 **<4500kg** 的汽车列车，如拖挂式房车）                     |
| **D**  | 普通三轮摩托车（排量 **>50ml** 或设计车速 **>50km/h**）+ 普通二轮、轻便摩托车      |
| **E**  | 普通二轮摩托车（排量 >50ml 或设计车速 >50km/h）+ 轻便摩托车                   |
| **F**  | 轻便摩托车（排量 **≤50ml**、设计车速 **≤50km/h**）                     |
| **M**  | 轮式专用机械车                                                  |
| **N**  | 无轨电车                                                     |
| **P**  | 有轨电车                                                     |

| **增驾**   | <font color="#f79646">大型客车、重型牵引挂车</font><font color="#f79646">、</font>城市公交、<font color="#f79646">中型客车、</font>大型货车、小型汽车、小型自动挡、<font color="#f79646">轻型牵引挂车、</font>低速载货、三轮汽车、普通三轮/二轮摩托、轻便摩托、轮式专用机械、无轨电车、有轨电车 |

### 2.2 年龄条件

| 准驾车型                          | 年龄                               |
| ----------------------------- | -------------------------------- |
| 小型汽车、C2、C5、轻便摩托车              | **18 周岁以上**（70 周岁以上需通过能力测试，每年体检） |
| 低速载货、三轮汽车、普通三轮/二轮摩托、轮式专用机械    | **18–60 周岁**                     |
| 城市公交、中型客车、大型货车、轻型牵引挂车、无轨/有轨电车 | **20–60 周岁**                     |
| 大型客车、重型牵引挂车                   | **22–60 周岁**                     |
| 全日制驾驶职业教育学生申请大型客车/重型牵引挂车      | **19–60 周岁**                     |

### 2.3 身体条件

|   项目     | 要求                                                       |
| -------- | -------------------------------------------------------- |
| **身高**   | A1/A2/A3/B2/N：**≥155cm**；B1：**≥150cm**                   |
| **视力**   | A1/A2/A3/B1/B2/N/P：裸眼或矫正 **5.0 以上**；C1/C2 等其他：**4.9 以上** |
| **辨色力**  | 无红绿色盲                                                    |
| **听力**   | 两耳距音叉 **50cm** 能辨别声源方向；有听力障碍但戴助听设备可达标的，可申请 C1/C2         |
| **上肢**   | 双手拇指健全，每只手其他手指有三指健全；手指末节残缺或左手三指健全，可申请 C5                 |
| **下肢**   | 双下肢健全、运动功能正常，不等长度 **≤5cm**；单独左下肢缺失或丧失功能但右下肢正常，可申请 C5     |
| **躯干颈部** | 无运动功能障碍                                                  |
| **特殊情况** | 双下肢缺失但能自主坐立且上肢合格，或一只手掌缺失但另一手条件达标且下肢合格，可申请 C5             |

### 2.4 恢复驾驶资格（7 种情形）

原驾驶证因下列原因被注销的，可直接申请相应准驾车型考试：
1. 超过有效期未换证
2. 未提交身体条件证明
3. 本人申请注销
4. 身体条件暂时不符合规定
5. 其他原因被注销（被吊销或撤销的除外）
6. 军队/武装警察部队驾驶证超过有效期
7. 境外驾驶证超过有效期

> 第 6、7 项还须提交超过有效期的驾驶证。

### 2.5 不得申请驾驶证的情形（9 种）

1. 有妨碍安全驾驶的疾病（器质性心脏病、癫痫、美尼尔氏症、眩晕症、癔病、震颤麻痹、精神病、痴呆、影响肢体活动的神经系统疾病等）
2. **3 年内**有吸食/注射毒品，或解除强制隔离戒毒未满 3 年，或长期服用依赖性精神药品未戒除
3. 造成交通事故后逃逸构成犯罪
4. 饮酒/醉酒驾驶发生重大交通事故构成犯罪
5. 醉酒驾驶或饮酒后驾驶营运机动车被吊销，**未满 5 年**
6. 醉酒驾驶营运机动车被吊销，**未满 10 年**
7. 因其他情形被吊销，**未满 2 年**
8. 驾驶许可被撤销，**未满 3 年**
9. 其他法定情形

## 四、培训与考试

### 4.1 培训内容

四部分：道路交通安全法律法规和相关知识、基础和场地驾驶、道路驾驶、安全文明驾驶常识。

- 每天课堂学习 **≤4 学时**，实际操作 **≤4 学时**
- 学时 **60 分钟**，不得低于 **45 分钟**
- 先学法规并考试合格，再学驾驶技能
- 上路学习须用教练车，在指定路线/时间、教练员随车指导下进行；与教学无关人员不得  乘坐
- 学员学习中有违法或造成事故，由**教练员承担责任**

### 4.2 考试科目与合格标准

| 科目              | 内容                                                                                       | 满分  | 合格       |
| --------------- | ---------------------------------------------------------------------------------------- | --- | -------- |
| **科目一**         | 道路交通安全法律法规和相关知识                                                                          | 100 | **90 分** |
| **科目二**         | 场地驾驶：倒车入库、坡道定点停车和起步(C1)、侧方停车、曲线行驶、直角转弯                                                   | 100 | **80 分** |
| **科目三（道路驾驶）**   | 上车准备、起步、直线行驶、加减挡、变更车道、靠边停车、直行通过路口、路口左/右转弯、通过人行横道/学校/公交站、会车、超车、掉头、夜间行驶（里程 ≥3 公里，白天模拟夜间灯光） | 100 | **90 分** |
| **科目三（安全文明常识）** | 安全文明驾驶、恶劣天气/复杂道路、紧急情况处置、伤员急救                                                             | 100 | **90 分** |
  
> **C2 自 2021-6-1 起取消坡道定点停车和起步考试**。

### 4.3 考试预约

- 科目一合格后，可预约科目二或科目三；有条件地区可同时预约、连续考试
- 科目二、科目三道路驾驶技能均合格后，可当日参加科目三安全文明驾驶常识考试
- 科目一合格后 **1 日内**核发学习驾驶证明
- 学习驾驶证明满 **10 日**可约科目二（C1/C2/C3/C4/C5/M/N/P）
- 学习驾驶证明满 **30 日**可约科目三（C1/M/N/P）；C2/C5/C3/C4 满 **20 日**
- 每科目考试一次，不合格可补考一次；补考仍不合格本次终止，重新预约；科目二/三应在 **10 日后**预约
- 科目三安全文明常识不合格的，已通过的道路驾驶技能成绩**有效**

### 4.4 学习驾驶证明

- 科目一合格后 **1 日内**核发，是场地和上路学习驾驶的**唯一合法凭证**
  - 纸质与电子形式具有同等效力
- 有效期 **3 年**，须在有效期内完成科目二、科目三；逾期未完成，已合格科目成绩作废
- 有效期内科目二、科目三道路驾驶技能预约次数 **不得超过 5 次**；第 5 次仍不合格，已合格的其他科目成绩作废
- 上路学习未随身携带，罚 **20–200 元**

## 五、使用规定

### 5.1 发证
- 领证宣誓仪式当日核发
- 增驾的，收回原驾驶证
- 复原、转业、退伍的，收回军队/武装警察部队驾驶证

### 5.2 实习期

- **定义**：初次取得**汽车类**或**摩托车类**准驾车型后的 **12 个月**
- 车身后部粘贴或悬挂统一式样**实习标志**
- 上高速公路须由持相应或更高准驾车型驾驶证 **3 年以上**的驾驶人陪同（C5 可由 C2 以 上陪同）
- 实习期内**不得驾驶**：公共汽车、营运客车、执行任务的警车/消防车/救护车/工程救险车、载有危险物品的机动车；不得牵引挂车
- 增驾后的实习期内，驾驶**原准驾车型**不受上述限制

### 5.3 补证

- 遗失向核发地或核发地以外车管所申请，提交身份证明，**1 日内**补发
- 被扣押、扣留或暂扣期间**不得申请补发**
- 补领后原证作废，不得继续使用；继续使用原证收回并罚 **20–200 元**
- 被扣期间以隐瞒、欺骗手段补领：收回原证，罚 **200–500 元**

### 5.4 换证（3 类）

| 类型         | 要求                                                      |
| ---------- | ------------------------------------------------------- |
| **有效期满换证** | 有效期满前 **90 日内**申请；提交身份证明、身体条件证明（C5 需省级卫生主管部门指定专门医疗机构出具） |
| **户籍迁出换证** | 并申报身体条件情况                                               |
| **其他原因换证** | 信息变化或驾驶证损毁无法辨认，**30 日内**申请；填申请表 + 身份证明 + 驾驶证            |

## 六、审验制度

### 6.1 审验要求
- 有效期满、户籍迁出原车管所管辖区换证时，应接受审验
- 持 **A1/A2/A3/B1/B2** 驾驶证，一个记分周期内**有记分**的；以及持 C1/C2 等准驾车型、发生交通事故致人死亡承担**同等以上责任**未被吊销的，应在记分周期结束后 **30 日内**接受审验
- 可在核发地或以外地方参加审验、提交身体条件证明

### 6.2 审验内容
1. 道路交通安全违法行为、交通事故处理情况
2. 身体条件情况
3. 违法记分及记满 12 分后参加学习和考试情况

> 持 C1 等驾驶证发生事故致人死亡承担同等以上责任未被吊销的，审验时应参加不少于 **3 小时**的学习并接受警示教育。
> 违法/事故未处理完毕、身体条件不符合、未按规定学习考试教育的，**不予通过审验**。

### 6.3 延期审验
因服兵役、出国等无法按期办理期满换证、审验、提交身体条件证明的，可在有效期内或有效期届满 **1 年内**申请延期；**延期最长不超过 3 年**；延期期间**不得驾驶机动车**。

### 6.4 身体检查
- **70 周岁以上**：每年体检一次，记分周期结束后 **30 日内**提交
- **C5**：每 **3 年**体检一次，记分周期结束后 30 日内提交

## 七、注销规定（12 种情形）

车辆管理所应当注销驾驶证的情形：
1. 死亡
2. 提出注销申请
3. 丧失民事行为能力，监护人提出注销申请
4. 身体条件不适合驾驶
5. 有妨碍安全驾驶的疾病
6. 被查获吸食/注射毒品后驾驶，正在执行社区戒毒、强制隔离戒毒、社区康复，或长期服用依赖性精神药品未解除
7. 超过有效期 **1 年以上**未换证
8. 70 周岁以上一个记分周期结束后 **1 年内**未提交体检证明；或 C5 三个记分周期结束后 1 年内未提交
9. 60 周岁以上只持 M/N/P，或 70 周岁以上只持 C3/C4
10. 驾驶证被依法吊销或驾驶许可被撤销
11. 实习期内记满 12 分，注销实习的准驾车型驾驶资格
12. 代替他人参加机动车驾驶人考试

**恢复驾驶资格**：
- 第 7 项注销未超过 **2 年**：参加科目一考试合格后恢复
- 第 8 项注销，驾驶证在有效期内或超过有效期不满 1 年：提交身体条件证明后恢复

## 九、易混对比

| 易混点 | 区分 |
|--------|------|
| C1 vs C2 | C1 可驾手动/自动小型汽车；C2 仅自动挡；C2 以上可驾 C5 |
| A1 vs A2 | A1 大型客车；A2 重型牵引挂车 |
| 初次申领 vs 增驾 | 初次**不能**申领 A1/A2/B1/C6；这些须增驾 |
| 科目一 vs 科目二合格分 | 科目一 90 分；科目二 80 分 |
| 实习期 vs 学习驾驶证明 | 实习期 = 取得驾照后 12 个月；学习驾驶证明 = 学车期间，有效期 3 年 |
| 有效期满换证 vs 其他原因换证 | 期满前 90 日内；信息变化/损毁 30 日内 |
| 延期审验 | 最长 3 年，延期期间不得驾驶 |
| 70 周岁 vs C5 体检 | 70 周岁以上每年；C5 每 3 年 |

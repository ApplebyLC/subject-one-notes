# 车辆检查·轮胎与油液

> **一句话考点**：日常检查分**出车前 / 行车中 / 收车后**；轮胎磨损极限 **1.6mm**；汽油 **89/92/95/98**；柴油按凝固点 **6 个牌号**。

---

## 一、车辆检查与维护

### 1.1 检查分类

| 类型 | 负责方 | 主要内容 |
|------|--------|---------|
| **日常检查与维护** | 驾驶人 | 清洁、补给、安全检视；分**出车前、行车中、收车后** |
| **一级维护** | 维修企业 | 以**清洁、润滑、紧固**为中心 |
| **二级维护** | 维修企业 | 一级维护 + 检查调整易磨损/变形安全部件，拆检轮胎、换位等 |

### 1.2 出车前检查

| 项目 | 要求 |
|------|------|
| **灯光** | 检查所有灯光外观和工作情况，脏污清洗、损坏更换 |
| **轮胎** | 检查气压（不足及时充气）；磨损标记处沟槽深度 **<1.6mm** 立即更换；裂纹/损伤及时检修；清除沟槽异物 |
| **机油** | 发动机启动前拔出机油尺，油位在 **MAX 与 MIN 之间**；低于下限按说明书规定牌号添加 |
| **冷却液** | 液面在 MAX 与 MIN 之间；低于下限按说明书添加 |
| **风窗玻璃清洗液** | 观察液面，需要添加时防止杂质混入 |
| **制动液** | 液面在 MAX 与 MIN 之间；明显减少时检查管路有无渗漏 |
| **行车证件及工具** | 证件齐全，随车装置、工具、备件齐全带足 |
| **车身外表** | 清洁车身；灯光照明装置和号牌完好清晰；外露螺栓紧固无松脱缺失 |

### 1.3 行车中检查

注意查看仪表，查听发动机及底盘声音，定期停车检视车外。发现**操纵困难、车身跳动/颤抖、机件异响/异味、冷却液温度异常**时，及时解决排除。

### 1.4 收车后检查

1. 检查无漏油、漏水、漏气；视需补充燃油、润滑油、冷却液
2. 检查轮胎气压符合要求，胎间及表面无杂物
3. 检查轮胎螺母和半轴螺母无松动

## 三、轮胎

### 3.1 作用
承担汽车重量、缓冲震动、保证与地面之间的附着力。现代汽车多采用**充气轮胎**。

### 3.2 正确使用要求

1. 同一辆车使用**同一尺寸、种类、构造**的轮胎
2. 按标准胎压充气；**至少每月一次**用气压表检查，且在轮胎**冷却状态**下检测
3. 检查无裂纹、无钉子/金属/玻璃/石块等异物，发现及时清除
4. 不使用有外伤或橡胶裂纹的轮胎
5. **沟槽深度仅剩 1.6mm** 即达使用极限，应在磨损限度标示露出前更换；过度磨损易在潮湿路面打滑
6. 内胎气压定期检查
7. 确认轮辋无裂纹、变形或明显腐蚀
8. 定期或根据磨损状况进行**轮胎换位**，防偏磨、异常震动和噪音
9. 检查气门有无老化、气门帽是否完好

### 3.3 更换方法

1. 停在安全平稳处，**拉紧驻车制动器**；路边换胎停到车流少处，按规定放置三角警告牌
2. 准备备胎、扳手、千斤顶；千斤顶顶在需换胎侧车架的**金属部分**
3. 用扳手拧松螺母卸下旧胎；**旧胎放车架下**，万一千斤顶失效可保护车辆
4. 装备胎，先用手拧紧螺母，再均匀拧到约 **70%**；稍放下千斤顶，按**对角线对称**完全拧紧

## 四、运行材料

### 4.1 车用汽油

| 项目  | 内容                                 |
| --- | ---------------------------------- |
| 牌号  | **89、92、95、98**（2017-1-1 起，国五排放标准） |
| 选用  | 按车辆使用说明书规定牌号加注                     |
| 规律  | **牌号越高，抗爆震性能越好**（爆震是气缸内不正常燃烧）      |

### 4.2 车用柴油

| 项目 | 内容 |
|------|------|
| 牌号 | 按凝固点分 **6 个牌号**：5号、0号、-10号、-20号、-35号、-50号 |
| 选用 | 依据**使用地温度**，按说明书选用 |
| 规律 | 柴油牌号越高，凝固点越高（原文表述） |

### 4.3 润滑油（机油）

| 项目 | 内容 |
|------|------|
| 作用 | 润滑、辅助冷却降温、密封防漏、防锈防蚀、减震缓冲 |
| 分类 | 冬季用油、非冬季用油、多季（四季通用）机油 |
| 冬季牌号 | **0W、5W、10W、15W、20W、25W**；W 代表冬季，W 前数字越小，低温黏度越小，低温流动性越好，适用最低气温越低 |
| 夏季牌号 | **20、30、40、50**；数字越大，黏度越大，适用最高气温越高 |
| 注意 | 按说明书选用、定期更换；**不同牌号不能混用** |

### 4.4 冷却液

| 项目 | 内容 |
|------|------|
| 作用 | 发动机冷却系统的冷却介质，由蒸馏水与防冻剂按比例配制；比例不同，冰点不同 |
| 颜色 | 一般呈**绿色或红色** |
| 注意 | 按说明书选用、定期更换；**不同牌号不能混用** |

### 4.5 风窗玻璃清洗液（玻璃水）

| 项目 | 内容 |
|------|------|
| 作用 | 由蒸馏水、清洁剂和酒精配制，快速清除风窗玻璃灰尘与污渍 |
| 分类 | **夏季用、冬季用** |
| 注意 | 按气温选用；尽量避免混用不同牌号 |

> 🧪 自测：[运行材料](99_科目一自测题.md#09)

## 六、易混对比

| 易混点 | 区分 |
|--------|------|
| 日常检查 vs 一级维护 vs 二级维护 | 日常 = 驾驶人清洁补给；一级 = 维修企业清洁润滑紧固；二级 = 一级 + 检查调整易损件、拆检轮胎换位 |
| 出车前 vs 收车后 | 出车前查灯光/轮胎/机油/冷却液/制动液/证件；收车后查漏油漏水漏气、胎压、螺母松动 |
| 汽油 vs 柴油牌号 | 汽油看**抗爆性**（牌号越高越好）；柴油看**凝固点/气温**（按使用地温度选） |
| 机油 W 前数字 vs 夏季数字 | W 前越小越耐低温；夏季数字越大越耐高温 |
| 冷却液 vs 玻璃水 | 冷却液给发动机降温（绿/红）；玻璃水清洗风窗（分夏冬） |

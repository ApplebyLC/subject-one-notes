# 违法处罚·强制措施与汽车常识

> **一句话考点**：违法责任分**刑事 / 行政 / 强制措施**三层；汽车 = **发动机 + 底盘 + 车身 + 电气设备**。

---

## 一、刑法责任

### 1.1 交通肇事罪

| 情形 | 处罚 |
|------|------|
| 违反交通运输管理法规，发生重大事故，致人重伤、死亡或公司财产遭受重大损失 | **3 年以下有期徒刑或拘役** |
| 交通运输肇事后逃逸，或有其他特别恶劣情节 | **3 年以上 7 年以下有期徒刑** |
| 因逃逸致人死亡 | **7 年以上有期徒刑** |

### 1.2 危险驾驶罪

在道路上驾驶机动车，有下列情形之一的，**处拘役并处罚金**；同时构成其他犯罪的，依照处罚较重的规定定罪处罚：
1. 追逐竞驶，情节恶劣
2. 醉酒驾驶机动车
3. 从事校车业务或旅客运输，严重超过额定成员载客，或严重超过规定时速行驶
4. 违反危险化学品安全管理规定运输危险化学品，危及公共安全

### 1.3 危险物品肇事罪

违反爆炸性、易燃性、放射性、毒害性、腐蚀性物品的管理规定，在生产、储存、运输、使用中发生重大事故，造成严重后果：
- **3 年以下有期徒刑或拘役**
- 后果特别严重：**3 年以上 7 年以下有期徒刑**

### 1.4 伪造、变造、买卖、使用证件罪

| 行为 | 处罚 |
|------|------|
| 伪造、变造、买卖驾驶证 | **3 年以下有期徒刑、拘役、管制或剥夺政治权利，并处罚金** |
| 情节严重 | **3 年以上 7 年以下有期徒刑，并处罚金** |
| 在应当提供身份证明的活动中，使用伪造、变造或盗用他人驾驶证，情节严重 | **拘役或管制，并处或单处罚金** |
| 同时构成其他犯罪 | 依照处罚较重的规定定罪处罚 |

## 二、道路交通安全违法处罚

### 2.1 处罚种类

| 种类 | 说明 |
|------|------|
| **警告** | 情节轻微、不影响道路通行的，指出违法行为，口头警告后放行 |
| **罚款** | 按违法行为严重程度分档 |
| **暂扣或吊销机动车驾驶证** | 严重违法 |
| **拘留** | 最严重 |

### 2.2 酒驾 / 醉驾处罚

| 情形                      | 处罚                                                          |
| ----------------------- | ----------------------------------------------------------- |
| 饮酒后驾驶机动车被处罚，**再次**饮酒后驾驶 | **10 日以下拘留 + 1000–2000 元罚款 + 吊销驾驶证6个月**                     |
| **醉酒**驾驶机动车             | 约束至酒醒 + 吊销驾驶证 + 依法追究刑事责任 + **5 年内**不得重新取得                   |
| 饮酒后驾驶**营运**机动车          | **15 日拘留 + 5000 元罚款 + 吊销驾驶证 + 5 年内**不得重新取得                  |
| **醉酒**驾驶**营运**机动车       | 约束至酒醒 + 吊销驾驶证 + 追究刑事责任 + **10 年内**不得重新取得；重新取得后**不得驾驶营运机动车** |
| 饮酒/醉酒驾驶发生重大交通事故，构成犯罪    | 追究刑事责任 + 吊销驾驶证 + **终生**不得重新取得                               |

### 2.3 超员 / 超载处罚

| 情形                      | 罚款             |
| ----------------------- | -------------- |
| 公路客运车辆载客超过额定成员          | **200–500 元**  |
| 超过额定成员 **20%** 或违反规定载货  | **500–2000 元** |
| 货运机动车超过核定载质量            | **200–500 元**  |
| 超过核定载质量 **30%** 或违反规定载客 | **500–2000 元** |

### 2.4 违法停车处罚

- 交警可指出违法行为，口头警告，令其立即驶离
- 驾驶人不在现场，或虽在现场但拒绝立即驶离、妨碍其他车辆行人通行：
  - **20–200 元罚款**
  - 可将机动车拖移至不妨碍交通的地点或指定地点
- 拖车**不得收费**，应及时告知停放地点
- 因采取不正确方法拖车造成机动车损坏的，交管部门承担**补偿责任**

### 2.5 证照违规处罚

| 情形                                | 处罚                            |
| --------------------------------- | ----------------------------- |
| 未悬挂号牌、未放置检验合格标志/保险标志、未随车携带行驶证/驾驶证 | **扣留机动车**，通知提供/补办，可警告；提供后及时退还 |
| 故意遮挡、污损或不按规定安装号牌                  | 警告或 **20–200 元罚款**            |

### 2.6 伪造变造牌证处罚

| 情形                                 | 处罚                                                 |
| ---------------------------------- | -------------------------------------------------- |
| 伪造、变造或使用伪造、变造的**登记证书、号牌、行驶证、驾驶证**  | 收缴 + 扣留机动车 + **15 日以下拘留 + 2000–5000 元罚款**；构成犯罪追究刑责 |
| 伪造、变造或使用伪造、变造的**检验合格标志、保险标志**      | 收缴 + 扣留机动车 + **10 日以下拘留 + 1000–3000 元罚款**；构成犯罪追究刑责 |
| 使用**其他车辆**的登记证书、号牌、行驶证、检验合格标志、保险标志 | 收缴 + 扣留机动车 + **2000–5000 元罚款**；提供合法证明/补办后退还        |

### 2.7 其他违法行为处罚

| 情形                      | 处罚                                                                       |
| ----------------------- | ------------------------------------------------------------------------ |
| 违反道路通行规定                | 警告或 **20–200 元罚款**                                                       |
| 非法安装警报器、标志灯具            | 强制拆除 + 收缴 + **200–2000 元罚款**                                             |
| 所有人/管理人未按规定投保交强险        | 扣留车辆至投保后 + 按规定投保最低责任限额应缴保险费的**两倍**罚款                                     |
| 驾驶拼装或已达报废标准的机动车上路       | 收缴 + 强制报废 + **200–2000 元罚款** + 吊销驾驶证                                     |
| 出售已达报废标准的机动车            | 没收违法所得 + **销售金额等额**罚款 + 收缴并强制报废                                          |
| 发生重大交通事故构成犯罪            | 追究刑事责任 + 吊销驾驶证                                                           |
| 事故后逃逸                   | 逃逸方承担**全部责任**（有证据证明对方也有过错可减轻）；吊销驾驶证且**终生**不得重新取得；尚不构成犯罪：**200–2000 元罚款** |
| 欺骗、贿赂等不正当手段取得机动车登记或驾驶许可 | 收缴证书 + 撤销登记/许可 + **3 年内**不得再次申请                                          |
| 欺骗、贿赂办理补换领牌证、检验合格标志等业务  | 警告或 **200 元以下罚款**                                                        |
|                         |                                                                          |

**处 200–2000 元罚款的其他违法行为（8 项）**：
1. 未取得驾驶证、驾驶证被吊销或暂扣期间驾驶机动车
2. 将机动车交由未取得驾驶证或驾驶证被吊销、暂扣的人驾驶
3. 造成交通事故后逃逸，尚不构成犯罪
4. 机动车行驶超过规定时速 **50%**
5. 强迫驾驶人违反法规和机动车安全驾驶要求驾驶，造成交通事故尚不构成犯罪
6. 违反交通管制规定强行通行，不听劝阻
7. 故意损毁、移动、涂改交通设施，造成危害后果尚不构成犯罪
8. 非法拦截、扣留机动车辆，不听劝阻，造成交通严重阻塞或较大财产损失

> 有第 2、4 项情形之一的，可并处**吊销驾驶证**；有第 1、3、5–8 项情形之一的，可并处 **15 日以下拘留**。

## 三、行政强制措施

### 3.1 强制措施种类

1. 扣留车辆
2. 扣留机动车驾驶证
3. 拖移机动车
4. 检验体内酒精、国家管制的精神药品、麻醉药品含量
5. 收缴物品
6. 法律法规规定的其他行政强制措施

### 3.2 扣留车辆的情形（8 种）

1. 上道路行驶的机动车未悬挂号牌、未放置检验合格标志/保险标志 
2. 有伪造、变造或使用伪造、变造的登记证书、号牌、行驶证、检验合格标志、保险标志、驾驶证，或使用其他车辆相关证件嫌疑
3. 未按规定投保交强险
4. 公路客运车辆或货运机动车超载
5. 机动车有被盗抢嫌疑
6. 机动车有拼装或达到报废标准嫌疑
7. 未办理剧毒化学品公路运输通行证，通过公路运输剧毒化学品
8. 非机动车驾驶人拒绝接受罚款处罚

> 发生交通事故因收集证据需要，可依法扣留事故车辆。
> 扣留后 **24 小时内**交所属交管部门；不得扣留车辆所载货物，应通知当事人自行处理；当事人接受处理或提供证明/手续后，应及时退还。

### 3.3 扣留驾驶证的情形（5 种）

1. 饮酒后驾驶机动车
2. 将机动车交由未取得驾驶证或驾驶证被吊销、暂扣的人驾驶
3. 机动车行驶超过规定时速 **50%**
4. 驾驶有拼装或达到报废标准嫌疑的机动车
5. 一个记分周期内累计记分达到 **12 分**

### 3.4 拖移机动车

- 违反停放、临时停车规定，驾驶人不在现场，或虽在现场但拒绝立即驶离，妨碍其他车辆行人通行
- 可拖移至不妨碍交通的地点或指定地点

### 3.5 检验体内酒精 / 管制药品

**应当检验体内酒精含量的情形**：
1. 对酒精呼气测试结果有异议，并当场提出
2. 涉嫌饮酒驾驶发生交通事故
3. 涉嫌醉酒驾驶
4. 拒绝配合酒精呼气测试

- 对呼气测试结果无异议的，应签字确认；事后提出异议的不予采纳
- 涉嫌吸食、注射毒品或服用管制精神药品/麻醉药品后驾驶的，按吸毒检测程序检测，并通知家属（无法通知除外）
- 酒后、吸毒后行为失控或拒绝配合检验检测的，可使用约束带或警绳等约束性警械
- 对检验结果有异议的，可在收到结果之日起 **3 日内**申请重新检验

### 3.6 收缴物品的情形（4 种）

1. 非法安装警报器、标志灯具，或自行车、三轮车加装动力装置
2. 扣留的拼装或已达到报废标准的机动车
3. 伪造、变造或使用伪造、变造的登记证书、号牌、行驶证、检验合格标志、保险标志、驾驶证
4. 使用其他车辆的登记证书、号牌、行驶证、检验合格标志、保险标志

### 3.7 车辆登记违规处罚

**警告或 200 元以下罚款（7 种）**：
1. 重型/中型载货汽车及挂车车身或车厢后部未按规定喷涂放大牌号，或牌号不清晰
2. 喷涂、粘贴标识或车身广告影响安全驾驶
3. 载货汽车、挂车未按规定安装侧面及后下部防护装置、粘贴车身反光标识
4. 未按规定期限进行安全技术检验
5. 改变车身颜色、更换发动机/车身/车架，未按规定时限办理变更登记
6. 所有权转移后，现所有人未按规定时限办理转移登记
7. 办理变更/转移/档案转出后，未按规定时限到住所地车管所申请转入

**擅自改变机动车外形和已登记的有关技术数据**：责令恢复原状 + 警告或 **500 元以下罚款**。

## 四、汽车基础常识

### 4.1 汽车的定义

**汽车**：由动力驱动，具有 **4 个或 4 个以上车轮**的非轨道承载车辆，主要用于载运人员或货物、牵引载运货物或特殊用途的车辆。

**机动车**：由动力装置驱动或牵引，上道路行驶的供人员乘用或用于运送物品以及进行工程专项作业的轮式车辆，包括：
- 汽车及汽车列车
- 摩托车
- 拖拉机运输机组
- 轮式专用机械车
- 挂车

### 4.2 汽车起源

| 时间 | 人物 | 事件 |
|------|------|------|
| **1769 年** | 法国人尼古拉·居纽 | 制造世界上第一辆真正意义的汽车（煤气燃烧产生蒸汽驱动的三轮汽车） |
| **1804 年** | 法国人特雷威迪克 | 设计出第一辆蒸汽汽车 |
| **1886 年** | 本茨和戴姆勒 | 申请以内燃机为动力的现代汽车发明专利，**汽车工业进入元年** |

### 4.3 燃油汽车四大部分

| 部分       | 作用                              | 组成                                                    |
| -------- | ------------------------------- | ----------------------------------------------------- |
| **发动机**  | 动力装置，将燃料燃烧产生的热能转变为机械能，为汽车行驶提供动力 | 两大机构：曲柄连杆机构、配气机构；五大系：冷却系、燃料供给系、润滑系、点火系、启动系（柴油机少一个点火系） |
| **底盘**   | 接受发动机动力，使汽车运动并按驾驶人操纵正常行驶        | 传动系、行驶系、转向系、制动系                                       |
| **车身**   | 为乘客和货物提供空间，也是其他部件安装的载体          | —                                                     |
| **电气设备** | 为汽车提供运行所需用电                     | 电源、蓄电池、用电设备（空调、刮水器、照明与信号装置等）、电子控制装置（电控单元、网络系统等）       |

### 4.4 纯电动汽车

与燃油汽车不同，纯电动汽车以**电力驱动**，由**电机系统、电控系统、电池系统**取代发动机设备。

### 4.5 行驶基本原理

燃油汽车：发动机燃用燃料产生动力 → 动力传递装置 → 驱动轮 → 产生路面对汽车的**牵引力** → 克服行驶阻力 → 正常运行。

## 六、易混对比

| 易混点 | 区分 |
|--------|------|
| 饮酒 vs 醉酒（非营运） | 饮酒：暂扣驾驶证 + 罚款；再次饮酒：10 日以下拘留 + 1000–2000 + 吊销；醉酒：约束至酒醒 + 吊销 + 刑责 + 5 年禁 |
| 饮酒 vs 醉酒（营运） | 饮酒营运：15 日拘留 + 5000 + 吊销 + 5 年禁；醉酒营运：吊销 + 刑责 + 10 年禁，且终身不得驾驶营运车 |
| 超员 20% / 超载 30% | 公路客运超 20% → 500–2000；货运超 30% → 500–2000；未达分水岭均为 200–500 |
| 伪造证件 vs 伪造标志 | 证件（登记证书/号牌/行驶证/驾驶证）：15 日拘留 + 2000–5000；标志（检验合格/保险）：10 日拘留 + 1000–3000 |
| 使用他车证件 vs 伪造证件 | 使用他车证件：2000–5000 罚款（无拘留）；伪造：拘留 + 罚款 |
| 扣留车辆 vs 扣留驾驶证 | 车辆：号牌/标志/保险/超载/盗抢/拼装等 8 种；驾驶证：酒驾/交无证人/超速 50%/拼装报废/满 12 分 5 种 |
| 交通肇事罪 vs 危险驾驶罪 | 肇事罪是**结果犯**（重大事故）；危险驾驶罪是**行为犯**（追逐、醉驾、严重超员超速、危化品） |

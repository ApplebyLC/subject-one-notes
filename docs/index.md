## 笔记构成

每篇笔记按同一个结构展开：从核心问题出发，展开知识框架，再处理记忆、辨析和复习。这五个部分对应一条从理解到复习的路径。

<div id="table-accent"></div>

| 部分 | 在结构中的位置 |
|------|--------------|
| 一句话考点 | 提出本篇要解决的问题 |
| 分层要点 | 展开知识框架 |
| 速记口诀 | 处理需要记忆的内容 |
| 易混对比 | 处理容易混淆的规则 |
| 数字汇总 | 汇总复习要点 |

阅读时建议先通读要点，再借助口诀和汇总记忆，最后用自测题检验。复习时可以反过来，从考点和汇总入手。

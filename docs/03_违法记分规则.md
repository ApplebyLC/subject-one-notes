# 违法记分规则

> **一句话考点**：记分周期 **12 个月**、满分 **12 分**；一次违法行为按严重程度记 **12 / 9 / 6 / 3 / 1 分**，共 5 档。

---

## 一、记分制度总览

| 记分周期 | **12 个月**                               |
| ---- | --------------------------------------- |
| 项目   | 规定                                      |
| 满分   | **12 分**                                |
| 起算时间 | 初次领取机动车驾驶证之日起连续计算；或初次取得临时机动车驾驶许可之日起累计计算 |
| 计分档次 | **12 分、9 分、6 分、3 分、1 分**，共 5 种          |

---

## 二、一次记 12 分的违法行为（7 项）

| 序号 | 违法行为 |
|------|---------|
| 1 | 饮酒后驾驶机动车 |
| 2 | 造成致人轻伤以上或者死亡的交通事故后逃逸，尚不构成犯罪 |
| 3 | 使用伪造、变造的机动车号牌、行驶证、驾驶证、校车标牌，或者使用其他机动车号牌、行驶证 |
| 4 | 驾驶校车、公路客运汽车、旅游客运汽车载人超过核定人数 **20% 以上**；或驾驶其他载客汽车载人超过核定人数 **100% 以上** |
| 5 | 驾驶校车、中型以上载客载货汽车、危险物品运输车辆在高速公路、城市快速路上超速 **20% 以上**；或驾驶其他机动车在高速公路、城市快速路上超速 **50% 以上** |
| 6 | 驾驶机动车在高速公路、城市快速路上**倒车、逆行、穿越中央分隔带掉头** |
| 7 | 代替实际机动车驾驶人接受交通违法行为处罚和记分，谋取经济利益 |

> 🧪 自测：[一次记 12 分的违法行为](99_科目一自测题.md#03)

## 三、一次记 9 分的违法行为（7 项）

| 序号 | 违法行为 |
|------|---------|
| 1 | 驾驶 **7 座以上**载客汽车载人超过核定人数 **50% 以上未达到 100%** |
| 2 | 驾驶校车、中型以上载客载货汽车、危险物品运输车辆在高速公路、城市快速路**以外**的道路上超速 **50% 以上** |
| 3 | 驾驶机动车在高速公路或城市快速路上**违法停车** |
| 4 | 驾驶**未悬挂**机动车号牌，或**故意遮挡、污损**机动车号牌的机动车上道路行驶 |
| 5 | 驾驶与**准驾车型不符**的机动车 |
| 6 | **未取得校车驾驶资格**驾驶校车 |
| 7 | 连续驾驶中型以上载客汽车、危险物品运输车辆**超过 4 小时**未停车休息，或停车休息时间**少于 20 分钟** |

> 🧪 自测：[一次记 9 分的违法行为](99_科目一自测题.md#03)

## 四、一次记 6 分的违法行为（11 项）

| 序号 | 违法行为 |
|------|---------|
| 1 | 载人超员：①校车/公路客运/旅游客运超 **未达 20%**；②7 座以上载客汽车超 **20%–50%**；③其他载客汽车超 **50%–100%** |
| 2 | 校车、中型以上载客载货汽车、危险物品运输车辆：①在高速/城市快速路超速 **未达 20%**；②在其他道路超速 **20%–50%** |
| 3 | 上述车辆**以外**的机动车：①在高速/城市快速路超速 **20%–50%**；②在其他道路超速 **50% 以上** |
| 4 | 驾驶载货汽车载物超过最大允许总质量 **50% 以上** |
| 5 | 载运爆炸物品、易燃易爆化学物品及剧毒、放射性等危险物品，未按指定时间、路线、速度行驶，或未悬挂警示标志并采取必要安全措施 |
| 6 | 运载超限的不可解体物品，未按指定时间、路线、速度行驶，或未悬挂警示标志 |
| 7 | 运输危险化学品，未经批准进入危险化学品运输车辆限制通行区域 |
| 8 | **不按交通信号灯指示通行**（闯红灯） |
| 9 | 机动车驾驶证被**暂扣或扣留期间**驾驶机动车 |
| 10 | 造成致人**轻微伤或财产损失**的交通事故后逃逸，尚不构成犯罪 |
| 11 | 在高速公路或城市快速路上**违法占用应急车道**行驶 |

> 🧪 自测：[一次记 6 分的违法行为](99_科目一自测题.md#03)

## 五、一次记 3 分的违法行为（15 项）

| 序号 | 违法行为 |
|------|---------|
| 1 | 校车、公路客运、旅游客运、7 座以上载客汽车**以外**的其他载客汽车，载人超 **20%–50%** |
| 2 | 校车、中型以上载客载货汽车、危险物品运输车辆**以外**的机动车，在高速/城市快速路以外道路超速 **20%–50%** |
| 3 | 在高速公路或城市快速路上**不按规定车道行驶** |
| 4 | 不按规定**超车、让行**，或在高速/城市快速路以外道路**逆行** |
| 5 | 遇前方停车排队或缓慢行驶时，**借道超车、占用对面车道、穿插等候车辆** |
| 6 | 有**拨打、接听手持电话**等妨碍安全驾驶的行为 |
| 7 | 行经**人行横道**不按规定减速、停车、避让行人 |
| 8 | 不按规定**避让校车** |
| 9 | 载货汽车载物超过最大允许总质量 **30%–50%**，或违反规定载客 |
| 10 | 驾驶**不按规定安装机动车号牌**的机动车上道路行驶 |
| 11 | 车辆发生故障、事故停车后，**不按规定使用灯光或设置警告标志** |
| 12 | 驾驶未按规定定期检验的**公路客运、旅游客运、危险物品运输车辆**上道路行驶 |
| 13 | 校车上路前未检查车况是否符合安全技术要求，或驾驶存在安全隐患的校车上路 |
| 14 | 连续驾驶**载货汽车**超过 4 小时未休息，或休息少于 20 分钟 |
| 15 | 在高速公路上行驶**低于规定最低时速** |

> 🧪 自测：[一次记 3 分的违法行为](99_科目一自测题.md#03)

## 六、一次记 1 分的违法行为（10 项）

| 序号  | 违法行为                                               |
| --- | -------------------------------------------------- |
| 1   | 校车、中型以上载客载货汽车、危险物品运输车辆，在高速/城市快速路以外道路超速 **10%–20%** |
| 2   | 不按规定**会车**，或在高速/城市快速路以外道路不按规定**倒车、掉头**             |
| 3   | 不按规定**使用灯光**                                       |
| 4   | 违反**禁令标志、禁止标线**指示                                  |
| 5   | 载货**长度、宽度、高度**超过规定                                 |
| 6   | 载货汽车载物超过最大允许总质量**未达到 30%**                         |
| 7   | 驾驶未定期检验的**公路客运、旅游客运、危险物品运输车辆以外**的机动车上道路行驶          |
| 8   | 驾驶**擅自改变已登记结构、构造或特征**的载货汽车上道路行驶                    |
| 9   | 驾驶人**未按规定系安全带**                                    |
| 10  | 驾驶摩托车**不戴安全头盔**                                    |

> 🧪 自测：[一次记 1 分的违法行为](99_科目一自测题.md#03)

## 七、满分处理

> 在一个记分周期内，**二次累计记分满 12 分**，或**累计记分满 24 分未满 36 分**的，公安机关交通管理部门应当**扣留其机动车驾驶证**。

> 🧪 自测：[满分处理](99_科目一自测题.md#03)

## 八、速记口诀

| 分值       | 口诀            | 对应                                                 |
| -------- | ------------- | -------------------------------------------------- |
| **12 分** | 酒逃伪，高倒代       | 酒驾；逃逸（轻伤以上）；伪造牌证；高速倒车/逆行/掉头；代扣分                    |
| **9 分**  | 高速违停、车不对证、牌不挂 | 高速违停；准驾不符；号牌未挂/遮挡；校车资格；超员 50%–100%；严重超速；疲劳驾驶（中型以上） |
| **6 分**  | 红灯应急，扣证还开     | 闯红灯；占应急车道；暂扣/扣留期驾驶；轻微伤逃逸；超载超速中等档；危险品违规             |
| **3 分**  | 电话不让，超车乱来     | 接打电话；不避让行人/校车；违规超车/穿插；不按车道；故障不设警示；低速行驶；疲劳驾驶（货车）    |
| **1 分**  | 带盔灯，会倒掉       | 不系安全带；不戴头盔；违规用灯；违规会车/倒车/掉头；违反禁令标志；载货超限             |

## 九、易混对比

| 易混点                       | 区分                                                                                                             |
| ------------------------- | -------------------------------------------------------------------------------------------------------------- |
| **超员**：12 分 vs 9 分 vs 6 分 | 校车/公路客运/旅游客运：超 20% 以上 → **12**；7 座以上：50%–100% → **9**；其他载客汽车：100% 以上 → **12**，50%–100% → **6**，20%–50% → **3** |
| **超速**（高速/城市快速路）          | 校车/中型以上/危险品：20% 以上 → **12**；未达 20% → **6**；其他机动车：50% 以上 → **12**，20%–50% → **6**                               |
| **超速**（其他道路）              | 校车/中型以上/危险品：50% 以上 → **9**，20%–50% → **6**，10%–20% → **1**；其他机动车：50% 以上 → **6**，20%–50% → **3**                |
| **逃逸**                    | 轻伤以上/死亡 → **12 分**；轻微伤/财产损失 → **6 分**                                                                          |
| **疲劳驾驶**                  | 中型以上载客汽车/危险品运输车 → **9 分**；载货汽车 → **3 分**                                                                       |
| **号牌问题**                  | 伪造/变造/使用他车号牌 → **12 分**；未悬挂/故意遮挡污损 → **9 分**；不按规定安装 → **3 分**                                                  |
